# Diagramas de Casos de Uso

Este diretório reúne os diagramas de casos de uso.

- **diagrama0_visao_geral** — visão geral do sistema, com todos os atores
  e casos de uso.
- **diagrama1_gerente** — fluxo de criação e simulação de regra (Gerente
  de Vendas).
- **diagrama2_supervisor** — governança e auditoria (Supervisor de
  Vendas).
- **diagrama3_administrador** — administração de usuários (Administrador).
